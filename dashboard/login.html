What this login is, and is not
  • One shared operator account. There are no separate users or roles.
  • It guards the operator actions: reading the operator's messages, Approve and Reject, and the demo reset. The command feed and plant values are readable without it.
  • The session is a signed cookie that lasts 12 hours and ends when the gateway restarts. Wrong passwords are rate-limited.
  • The demo runs over plain HTTP on a local hotspot. A real deployment needs TLS and per-person accounts. We have not built those.
